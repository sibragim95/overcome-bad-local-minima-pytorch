# Overcome bad local minima pytorch
PyTorch re-implementation of the numerical simulations from the research paper 'Convergence to good non-optimal critical points in the training of neural networks: Gradient descent optimization with one random initialization overcomes all bad non-global local minima with high probability' ([arXiv:2212.13111](https://arxiv.org/abs/2212.13111)). Originally written in TensorFlow 1.x.
